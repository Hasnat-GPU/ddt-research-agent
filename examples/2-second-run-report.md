# What model sizes does the NVIDIA Nemotron 3 family include?

Date: 2026-10-18T15:10:46 | Model: nvidia/nemotron-3-super-120b-a12b | Topic: nvidia nemotron | Evidence bar: 1

## Answer

The Nemotron 3 family includes Nano, Super and Ultra sizes. [1]  
The Nemotron 3 Nano is a compact 30B‑parameter model with 3B active parameters per token, while the Nemotron 3 Super is a 120 billion‑parameter (active 12 billion) hybrid Mamba‑Attention Mixture‑of‑Experts model. [2][3]

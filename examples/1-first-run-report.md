# What model sizes does the NVIDIA Nemotron 3 family include?

Date: 2026-10-18T15:09:43 | Model: nvidia/nemotron-3-super-120b-a12b | Topic: nvidia nemotron | Evidence bar: 1

## Answer

The Nemotron 3 family comprises Nano, Super, and Ultra model sizes[1]
Nemotron 3 Nano is a compact 30B‑parameter model with 3B active parameters per token[2]
Nemotron 3 Super is a 120 billion‑parameter (active 12 billion) hybrid Mamba‑Attention Mixture‑of‑Experts model[3]
Nemotron 3 Ultra is an open‑weight large language model with 550 billion total parameters[4]
